# PDF 매뉴얼 플립북 (Interactive 3D PDF Manual Flipbook)

실제 종이 책자처럼 사실적인 3D 넘김 애니메이션 효과로 PDF 매뉴얼을 열람할 수 있는 웹 플립북 애플리케이션입니다.

## 주요 기능
- **3D 인터랙티브 책장 넘김**: 마우스 드래그, 모서리 클릭, 키보드 방향키(`←`, `→`), 스와이프를 통한 책 넘김 애니메이션
- **PDF.js 기반 클라이언트 렌더링**: 별도 서버 변환 없이 브라우저에서 고해상도 벡터 PDF를 직접 렌더링
- **샘플 매뉴얼 내장 & 커스텀 PDF 업로드**: 데모 제품 매뉴얼 기본 제공 및 사용자 PDF 드래그앤드롭 업로드 지원
- **종이 넘김 사운드 이펙트**: Web Audio API로 구현된 리얼한 책장 넘김 효과음
- **뷰어 조작 도구**:
  - 이전/다음/첫/마지막 페이지 이동 및 직접 페이지 번호 점프
  - 확대/축소 (Zoom In/Out, 60% ~ 200%)
  - 단면 / 양면(스프레드) 보기 모드 전환
  - 자동 넘기기(Auto-play) 모드
  - 썸네일 목차 사이드바 (단축키 `T`)
  - 전체화면 토글 (단축키 `F`)

## 로컬 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (포트 3847)
npm run dev

# 빌드 및 프로덕션 실행
npm run build
npm run start
```
브라우저에서 `http://localhost:3847` 로 접속하여 플립북을 이용할 수 있습니다.
